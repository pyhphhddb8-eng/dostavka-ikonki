# Как поставить комплект на свой сайт

Инструкция для того, кто получил комплект и будет ставить его сам. Программистом
быть не нужно: всё сводится к тому, чтобы положить файлы и вставить кусок текста
в шапку каждой страницы.

## Что лежит в комплекте

**Папка `icons/`** — сам значок во всех размерах:

| Файл | Зачем |
|---|---|
| `favicon.svg` | Значок во вкладке в современных браузерах. Векторный, не мылится ни при каком увеличении. |
| `favicon.ico` | Тот же значок для старых браузеров. Внутри три кадра: 16, 32 и 48 пикселей. |
| `icon-16.png` … `icon-512.png` | Отдельные размеры. 16 — вкладка, 32 — закладка, 180 — iPhone, 192 и 512 — Android. |
| `apple-touch-icon.png` | Значок на домашнем экране iPhone. Без прозрачности: iOS подставляет вместо неё чёрный. |
| `icons/og/*.png` | Картинки превью 1200×630. По одной на каждую страницу. |

**`site.webmanifest`** — нужен ровно для одного: чтобы на домашнем экране
Android появился значок, а не обрезанный снимок страницы.

**`fonts/`** — шрифт, если он вам нужен. Вместе с ним обязательно лежит файл
лицензии `OFL.txt`: без него шрифт распространять нельзя.

## Куда положить файлы

Папку `icons/` и файл `site.webmanifest` — рядом с главной страницей сайта,
в корень. То есть так, чтобы значок открывался по адресу
`https://ваш-сайт.ru/icons/favicon.svg`.

Если ваш сайт живёт не в корне, а в подпапке — скажите об этом тому, кто будет
ставить: адреса в шапке придётся поправить.

## Что вставить в шапку каждой страницы

Между `<head>` и `</head>`. Одинаковая часть — для всех страниц:

```html
<link rel="icon" href="/icons/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/icons/favicon.ico" sizes="16x16 32x32 48x48">
<link rel="icon" type="image/png" sizes="192x192" href="/icons/icon-192.png">
<link rel="apple-touch-icon" sizes="180x180" href="/icons/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#0A2A66">

<meta property="og:type" content="website">
<meta property="og:site_name" content="Название вашей компании">
<meta property="og:locale" content="ru_RU">
<meta name="twitter:card" content="summary_large_image">
```

Разная часть — **своя на каждой странице**:

```html
<title>Заголовок страницы — Название компании</title>
<meta name="description" content="Описание страницы, 90–150 знаков.">
<link rel="canonical" href="https://ваш-сайт.ru/адрес-страницы.html">

<meta property="og:title" content="Заголовок страницы">
<meta property="og:description" content="Описание страницы, 90–150 знаков.">
<meta property="og:url" content="https://ваш-сайт.ru/адрес-страницы.html">
<meta property="og:image" content="https://ваш-сайт.ru/icons/og/адрес-страницы.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:type" content="image/png">

<meta name="twitter:title" content="Заголовок страницы">
<meta name="twitter:description" content="Описание страницы, 90–150 знаков.">
<meta name="twitter:image" content="https://ваш-сайт.ru/icons/og/адрес-страницы.png">
```

Три вещи, на которых спотыкаются чаще всего.

**Адрес картинки превью пишется полностью.** С `https://` и именем сайта.
Не `icons/og/promo.png` и не `/icons/og/promo.png`, а
`https://ваш-сайт.ru/icons/og/promo.png`. Мессенджер не знает, с какого сайта
пришла ссылка, и домен сам не подставит — карточка придёт без картинки.

**Название сайта не должно повторять заголовок страницы.** Telegram печатает
их одно под другим, и в карточке получаются две одинаковые строки. Название
сайта — это компания, заголовок — это про что страница.

**У каждой страницы своя картинка, свой заголовок и своё описание.** Одна
картинка на весь сайт — самая частая ошибка: человек пересылает в чат страницу
акции, а в карточке общее «мы служба доставки».

## Как проверить, что всё встало

1. Откройте сайт и посмотрите на вкладку браузера. Значок должен появиться.
   Если его нет — нажмите Ctrl+F5 (на Маке Cmd+Shift+R): браузер держит старый
   значок очень цепко.
2. Проверьте, что каждый объявленный файл действительно отдаётся. В комплекте
   для этого есть скрипт:

       python3 -m tools.check --live https://ваш-сайт.ru/

   Он пройдёт по всем страницам, дёрнет каждый файл из шапки и скажет, чего
   не хватает. Молчание — значит всё на месте.

## Мессенджер показывает старое превью

Это не ошибка установки. Мессенджер запоминает карточку, когда ссылку
пересылают в первый раз, и потом показывает запомненное — иногда неделями.

- **Telegram.** Отправьте адрес страницы боту **@WebpageBot**. Он сбросит
  запомненное, и следующая пересылка соберёт карточку заново.
- **ВКонтакте.** Есть свой отладчик Open Graph на сайте vk.com — вставьте туда
  адрес страницы.
- **WhatsApp.** Сброса нет. Помогает только новый адрес страницы.

Поэтому проверять карточку лучше сразу после установки, а не через месяц.

## Чего комплект не делает

**Не обещает одинаковый вид карточки во всех мессенджерах.** Правила у них
разные и меняются без предупреждения. Комплект даёт корректную разметку и
проверку — власти над чужими приложениями он не даёт.

**Не даёт офлайнового режима и установки сайта приложением.** Файл
`site.webmanifest` положен ради значка на домашнем экране, и только. Ни
кэширования страниц, ни работы без интернета в комплекте нет.

**Не занимается поисковой оптимизацией.** Теги `og:` читают мессенджеры и
социальные сети, а не Яндекс с Гуглом.
