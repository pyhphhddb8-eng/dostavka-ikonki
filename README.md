# Значок сайта и превью ссылок для службы доставки

Демо-сайт вымышленной службы доставки: три страницы, у каждой своё превью
для мессенджеров, полный комплект значков и витрина, показывающая результат.

Пятая из семи новых работ для портфолио профиля FL.ru `kusaka63`.

## С чего начать

Читать `docs/superpowers/specs/2026-09-21-dostavka-ikonki-design.md` — там
решение целиком: предмет, состав комплекта, сам знак, пять ошибок, которые
работа показывает, устройство и что проверяется.

Дальше по порядку: план работ, сборка, предпросмотр со скриншотом, правки,
выкладка на GitHub Pages.

## Состояние на 21.09.2026

Собрано и проверено. Выложено на GitHub Pages.

## Как собрать и проверить

Нужен только системный Python 3 — ни npm, ни установки пакетов.

Собрать весь комплект заново:

    python3 -m tools.build

Прогнать проверки по файлам:

    python3 -m tools.check

Прогнать проверки по живому адресу:

    python3 -m tools.check --live https://pyhphhddb8-eng.github.io/dostavka-ikonki/

Запустить тесты:

    python3 -m unittest discover -s tests

Посмотреть сайт у себя:

    python3 -m http.server 8000

и открыть http://localhost:8000/showcase.html — витрина работает только
по адресу http://, при открытии файла с диска браузер не даст ей прочитать
соседние страницы.

Новая страница сайта — это новая строка в `content/pages.tsv` и новый
HTML-файл с метками `head:begin` и `head:end` в шапке. Всё остальное
сделает `python3 -m tools.build`.

Инструкция для владельца чужого сайта, которому комплект передаётся:
`docs/УСТАНОВКА.md`.

## Чем отличается от работ на другом профиле

На `serhio2490` есть превью и значок для лендинга и есть значок для сайта
Экспертиза.ру. Там одна картинка на весь сайт, нарисованная руками. Здесь у
каждой страницы своё превью, картинки собирает скрипт из шаблона, а витрина
строит карточку из живых тегов страницы — разойтись с действительностью она
не может.

## Что работа показывает

Пять ошибок, которые в этой задаче делают чаще всего: относительный адрес
картинки превью, объявленный, но отсутствующий файл значка, название сайта,
повторяющее заголовок, одна картинка на все страницы и значок, читаемый
только крупно. Каждая проверяется, а не объявляется.

## Две оговорки

**Витрина — макет из живых тегов, а не снимок из чата.** Показать настоящую
переписку я не могу, а выдавать рисунок за скриншот нельзя.

**Манифест кладётся ради значка на домашнем экране.** Ни офлайнового режима,
ни установки приложением в работе нет.

## Ловушка, о которой стоит помнить при сборке

Демо закрывается от поисковиков мета-тегом, а не запретом в `robots.txt`:
боты мессенджеров читают `robots.txt`, и глухой `Disallow` оставит работу про
превью ссылок без превью.
